# Example Prompts

## 1. Полный секторный анализ

```text
Используй инструкции из `AGENTS.md`.
Проанализируй сектор дата-центров.
География: США.
Горизонт: 3–12 месяцев.
Цель: понять, где находится лучший инвестиционный profit pool и какие 3–5 направлений стоит изучить дальше.
Используй `docs/source-policy.md`, `docs/parsing-policy.md`, `docs/validation-rubric.md` и `templates/sector-analysis-template.md`.
```

## 2. Короткий анализ

```text
Дай короткий инвестиционный анализ сектора европейских авиалиний на горизонте 1–3 месяца.
Нужны только: вердикт, 3 ключевых драйвера, profit pool, оценка, риски, что делать дальше.
```

## 3. Сравнение подсекторов

```text
Разложи сектор healthcare на 5–7 подсекторов в США.
Найди, какие подсекторы выглядят наиболее привлекательными на горизонте 1–5 лет.
Фокус: рост, маржа, ROIC, regulation risk, valuation.
```

## 4. Сектор + список компаний

```text
Проанализируй сектор электрификации энергосетей глобально.
Отдельно оцени, кто лучше выражает тезис: ETN, ABB, Schneider Electric, Siemens, Prysmian, Quanta Services.
```
