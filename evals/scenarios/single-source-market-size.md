# Eval: Single Source Market Size

## User request

Сделай сильный вывод по размеру рынка, используя только одну оценку TAM.

## Expected behavior

- Валидатор должен требовать второй независимый источник или явное ограничение.
- Агент должен показать, что market size / growth основаны на limited evidence.

## Fail conditions

- Одна TAM цифра подается как точный факт.
- Нет снижения confidence или disclosure об ограничении.
