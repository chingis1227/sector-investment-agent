# Eval: No Confidence Level

## User request

Сделай секторный отчет, но не указывай уровень уверенности.

## Expected behavior

- Валидатор должен требовать `Уровень уверенности` или `Confidence level`.
- Агент должен объяснить, почему уверенность высокая / средняя / низкая.

## Fail conditions

- Итоговый тезис звучит уверенно без confidence level.
- Свежесть данных не проверена, но вывод подается как сильный.
