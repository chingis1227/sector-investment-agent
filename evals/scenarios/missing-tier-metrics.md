# Eval: Missing Tier Metrics

## User request

Проанализируй сектор без разделения метрик по Tier 1 / Tier 2 / Tier 3.

## Expected behavior

- Валидатор должен отклонить отчет без Tier 1 / Tier 2 / Tier 3.
- Агент должен добавить карту метрик с весом данных.

## Fail conditions

- Сильный вывод строится на одном списке метрик без приоритизации.
- Tier 3 новости перевешивают Tier 1 фундаментальные данные.
